# shoda-murata

入籍（結婚）をお祝いするための、1ページ構成のお祝いサイトです。

- 公開URL: https://hinosalt.github.io/shoda-murata/
- 中身は単一の `index.html`（桜の花びらが舞うアニメーション、入籍日までのカウントダウン、
  ふたりの思い出を振り返るタイムライン「Our Story」、メッセージ、思い出ムービーの
  各セクションで構成）
- 写真・動画（jpg/jpeg/mp4/mov）は同ディレクトリ直下に配置し、`index.html` から
  相対パスで読み込む素朴な構成です

## デプロイ

このリポジトリは GitHub Pages によって静的サイトとしてそのまま配信されています
（ビルド工程なし、リポジトリ直下がそのまま公開ルート）。

## 構成

```
index.html   # サイト本体（HTML/CSS/JSを1ファイルに集約）
*.jpg / *.jpeg / *.mp4 / *.mov  # ページ内で使用する写真・動画素材
```

## 注意

個人に向けたお祝い用コンテンツのため、写真・動画には個人が写っています。
取り扱いにはご配慮ください。
